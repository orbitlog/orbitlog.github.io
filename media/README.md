# Media Directory

把不需要被 TypeScript 直接打包的静态资源放在这里。

- `cats/`：猫咪照片。
- `blog/`：博客文章内引用的图片，建议每篇文章一个子目录。
- `profile/`：头像、个人照片、简介页图片。
- `projects/`：项目截图和演示图。
- `interests/`：兴趣模块图片。
- `travel/`：旅行相册。
- `life/`：生活碎片。
- `future/`：未来计划相关图片。

在页面或 Markdown 里引用时，路径从 `/media/...` 开始，例如 `/media/cats/napping.jpg`。
